公网模式

不在同一个局域网？用公网快传

上面那套需要两边连同一个 WiFi。如果你和对方隔着城市、隔着网， 用这个：上传后生成 6 位取件码，对方打开同一个网址输码就能下。 文件到期自动删除，每天有免费额度。

A 上传文件 → B 拿到取件码 → C 发给对方 → D 对方输码取件
打开公网快传 → 它能传多大？

额度：每天 500 MB + 20 次，单文件最大 100 MB，单次最多 20 个文件，次日零点重置。
有效期：默认 7 天，到期自动清理，也可以随时手动撤销。
登录：邮箱或手机号任选一种，收验证码即可，首次自动注册、不用设密码。 收发双方都得登录——这是平台存储的硬性限制，不是我们故意加的门槛。

Quick Start

三步，两分钟

不用装 Python，不用记 IP，不用输密码。
需要一台 Windows 电脑常开着。手里只有手机的话，直接用公网快传。

1

在电脑上下载 LanShare.exe

点这里下载（8.7 MB，免安装）
放进桌面或任意文件夹，双击就能跑。这个文件只能在 Windows 电脑上运行，手机装不了。

2

双击运行

黑窗口出现，浏览器自动打开页面。同一目录下会自动生成 shared/， 传进来的文件都在那儿。

3

手机扫一下

点页面上的「手机扫码」，手机相机对着屏幕扫 —— 直接进首页， 不用输 IP，也不用输 PIN。手机上照样能上传、下载、在线编辑。

Security

PIN 不是一个输入框，是一整套约束

局域网虽然小，但同一个 WiFi 下的人并不都是善意的。

✓
签名会话，伪造无效 登录凭证是 HMAC-SHA256 签名的 HttpOnly Cookie，改一个字节就作废。
✓
防暴力破解 同一 IP 连错 5 次锁 5 分钟，次数与时长都可调。
✓
原子比较，不泄时序 PIN 校验用 hmac.compare_digest，猜不出前几位对不对。
✓
路径锁死在 shared/ 里 任何 ../ 越界、绝对路径、符号链接都被拒绝。
✓
上传内容不当 HTML 解析 HTML 走沙箱响应头，没法在你的域下跑脚本偷 Cookie。
✓
只读模式 打开后只能看和下载，谁都不能改、不能删。适合把资料发给一群人。
⚠️ 想直接把这个服务放到公网？ 先读 README 那一节。HTTP 是明文的、6 位数字 PIN 在公网扛不住撞库， 至少套一层 HTTPS（Cloudflare Tunnel 最省事）并把 PIN 换成随机长串。 默认配置是给「自家 WiFi」用的，不是给互联网用的。
